INTERPRETATION
--------------------------------------------------------------------------------
The proposed risk-fusion layer changes the final decision distribution compared with the baseline.
GO changes from 4.28% to 2.79%.
SLOW changes from 72.78% to 50.68%.
STOP changes from 22.94% to 46.53%.

These results demonstrate decision-behavior changes introduced by risk fusion.
They should not be interpreted as safety-accuracy improvements because BDD100K does not provide GO/SLOW/STOP ground-truth labels for this experiment.

The controlled conflict test detected a disagreement between the Planning and Safety agents and produced a safety-prioritized STOP decision.

Natural agent conflicts in the 10,000-image evaluation: 0 (0.00%).

Temporal tracking and trajectory prediction are architecture components but are not fully evaluated using the static BDD100K image set.
